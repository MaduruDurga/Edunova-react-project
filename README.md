📘 Project Overview
Edunova Courses is an interactive educational website designed to offer a seamless experience for users looking to register, log in, and explore course content.

Built using React and powered by Firebase Authentication, the site ensures secure login and registration functionality with email verification and password reset options.

✨ Features
✅ User Registration & Login
📧 Email Verification & Password Reset
🔒 Secure Firebase Authentication
🧭 React Router-Based Navigation
🎨 Responsive UI Design
🚀 Deployed via Netlify

💡 Tech Stack
Frontend: React (with Vite)
Authentication: Firebase
Routing: React Router
Styling: CSS
Deployment: Netlify

🛠️ How to Run Locally

git clone https://github.com/MaduruDurga/Edunova-react-project.git
cd Edunova-react-project/frontend
npm install
npm run dev


📮 About
Edunova Courses is a modern, clean, and fast educational portal built to demonstrate user authentication and UI design using Firebase and React. It is suitable for students, learners, or developers exploring authentication-based React projects.
